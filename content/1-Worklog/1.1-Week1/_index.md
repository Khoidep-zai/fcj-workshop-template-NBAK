## Week 1: Getting Familiar with AWS and Core Services (04/05/2026 - 08/05/2026)

**Week 1 Objectives:**

- Connect with team members and get acquainted with the workflow at First Cloud AI Journey (FCAJ).
- Understand the overview of AWS Cloud, its core service categories, and how to use the Console & CLI.
- Understand the context and objectives of the Automated Cargo Quality Monitoring Solution project.

**Tasks completed this week:**

| Day | Task | Start Date | Completion Date | Reference |
|-----|------|------------|-----------------|-----------|
| Mon | Get acquainted with FCAJ team members and mentor. Read and memorize the internship regulations. Get a preliminary understanding of the Logistics cargo quality monitoring project objectives. | 04/05/2026 | 04/05/2026 | |
| Tue | Study the overview of AWS Cloud Computing. Learn about AWS core service categories: Compute, Storage, Networking, Database, AI/ML. | 05/05/2026 | 05/05/2026 | https://aws.amazon.com/what-is-aws/ |

**Week 1 Results:**

- Understood what AWS is and its core service categories: Compute, Storage, Networking, Database, AI/ML.
- Successfully created and configured an AWS Free Tier account.
- Installed and configured the AWS CLI on a personal machine.
- Understood the concepts of IAM User, Role, Policy, and the Least Privilege principle.
- Gained a clear understanding of the context and overall objectives of the Logistics cargo quality monitoring project to be developed over the 3-month internship.
